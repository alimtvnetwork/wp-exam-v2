# Quiz & Dynamic Form Engine — REST API Contracts

Version: 2.0.0  
Updated: 2026-09-18  
AI Confidence: Production-Ready  
Ambiguity: None  

## Overview

This specification establishes the authoritative REST API contracts for the WP Exam plugin under WordPress REST namespace `wp-exam/v1`. Following the `riseup-asia-uploader` architectural guidelines, all responses return the standardized Universal Response Envelope.

---

## 2. Public & Guest Endpoints

### 2.1. `GET /wp-json/wp-exam/v1/forms`
- **Access:** Public.
- **Purpose:** Returns active, published quizzes and forms.
- **Response `Results`:** Array of form summaries (omitting private question answers).

### 2.2. `GET /wp-json/wp-exam/v1/forms/{FormId}`
- **Access:** Public (if `FormAccess == 'public'`) or Authenticated.
- **Purpose:** Returns complete form structure and fields for the runner.
- **Security Guard:** If `FormType == 'quiz'`, the `CorrectAnswer` property is stripped from all fields to prevent cheating.

### 2.3. `POST /wp-json/wp-exam/v1/forms/{FormId}/submit`
- **Access:** Public or Authenticated (validated against `FormAccess`).
- **Purpose:** Submits answers for a quiz or dynamic form (e.g. Employee Sign-Up).
- **Request Payload:**
```json
{
  "GuestName": "Jane Doe",
  "GuestEmail": "jane.doe@company.com",
  "Answers": {
    "1": "Engineering",
    "2": "Full-Time",
    "3": "2026-10-01"
  }
}
```
- **Quiz Submission Result (`Results`):**
```json
{
  "SubmissionId": 42,
  "FormId": 5,
  "FormType": "quiz",
  "Score": 85,
  "TotalPossibleScore": 100,
  "ScorePercentage": 85.0,
  "IsPassed": true,
  "SubmittedAt": "2026-09-18T10:15:00Z"
}
```
- **Employee Sign-Up Result (`Results`):**
```json
{
  "SubmissionId": 43,
  "FormId": 6,
  "FormType": "employee_signup",
  "Message": "Employee sign-up recorded successfully.",
  "SubmittedAt": "2026-09-18T10:16:00Z"
}
```

## 3. Admin Management Endpoints (Requires `manage_options`)

### 3.1. `GET /wp-json/wp-exam/v1/admin/forms`
- **Purpose:** List all forms with full details, draft statuses, and total submission counts.

### 3.2. `POST /wp-json/wp-exam/v1/admin/forms`
- **Purpose:** Create a new quiz or form with fields and options.
- **Request Payload:**
```json
{
  "Title": "Employee Onboarding Intake Form",
  "Description": "Collects initial employee information and preferences.",
  "FormType": "employee_signup",
  "FormAccess": "public",
  "IsSequential": false,
  "IsPublished": true,
  "Settings": {
    "notificationEmail": "hr@company.com",
    "successMessage": "Thank you for submitting your onboarding details!"
  },
  "Fields": [
    {
      "FieldType": "short_answer",
      "FieldLabel": "Full Legal Name",
      "IsRequired": true,
      "DisplayOrder": 1
    },
    {
      "FieldType": "email",
      "FieldLabel": "Work Email",
      "IsRequired": true,
      "DisplayOrder": 2
    },
    {
      "FieldType": "dropdown",
      "FieldLabel": "Department",
      "IsRequired": true,
      "DisplayOrder": 3,
      "Options": ["Engineering", "Product", "Operations", "Sales"]
    }
  ]
}
```

### 3.3. `PUT /wp-json/wp-exam/v1/admin/forms/{FormId}`
- **Purpose:** Update form metadata, sequential mode, access policies, and fields.

### 3.4. `DELETE /wp-json/wp-exam/v1/admin/forms/{FormId}`
- **Purpose:** Delete a form and cascade delete its fields.

### 3.5. `GET /wp-json/wp-exam/v1/admin/forms/{FormId}/submissions`
- **Purpose:** Retrieve all submission entries for analysis, scoring review, or export.
