## 2. Question Card UI Modernization
- **Required Toggle:** Replace raw HTML checkbox `<input type="checkbox">` with `@/components/ui/switch` (Radix UI primitive) styled with label `Required Field`.
- **Terminology:** Eliminate "Section / Module". Standardize strictly on `Section`.
- **Scoring Points:** Wrap numeric points in styled badge container with clean typography.
- **Card Actions Dropdown:** Add `AI Instruction & Schema` option with `Sparkles` icon.
