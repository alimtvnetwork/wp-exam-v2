# Quiz Feature Skill

## Core Specifications
1. Backend: Custom tables (Quiz, QuizQuestion, QuizAnswer, QuizResult) and REST endpoints (/wp-json/quiz/v1/*).
2. Frontend: React + Tailwind UI with drag-and-drop question ordering and Zustand state store.
3. Coding standards: PascalCase database columns, typed Enums ending in Type, strict error handling.
