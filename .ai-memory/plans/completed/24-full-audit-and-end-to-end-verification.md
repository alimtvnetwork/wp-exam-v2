## 2. Comprehensive Requirements Audit & Implementation Matrix

| Feature Domain | Implementation Reference | Verification Outcome |
| :--- | :--- | :--- |
| **Local Runners** | `run.ps1`, `run.sh` | Spins up background PHP server (`8080`), compiles LESS, starts Vite (`5173`), auto-opens browser, and cleanly stops PHP on exit. |
| **Remote Deployment Uploader** | `scripts/uploader.php`, `BackupManager` UI | Targets Rise Up Asia REST API endpoints with Application Password / Bearer token authentication. |
| **Plugin Packaging Scripts** | `scripts/package-plugin.ps1`, `scripts/package-plugin.sh` | Generates installable `dist/wp-exam.zip` and `dist/wp-sam.zip`. |
| **Curriculum Topology** | `ProjectHierarchyManager` | Categories -> Projects -> Recursive Sub-Projects (`parent_project_id`), indented tree rendering with `└─` indicators. |
| **Pipeline Sequencing** | `ProjectHierarchyManager` | Interactive up/down controls allowing custom execution orders (e.g. Step A -> Step C -> Step D -> Step B). |
| **1-Click Project JSON Export/Import** | `ProjectHierarchyManager` | Exports complete project manifest to JSON and imports with schema validation and revision history snapshot. |
| **Split SQLite DB Architecture** | `SqliteDatabase.php`, `ProjectHistoryDatabase.php` | Isolated project databases (`wp-exam/projects/{id}.sqlite`) and audit history databases (`wp-exam/history/{id}_history.sqlite`) with 1-click rollback. |
| **4-Stage Learning State Machine** | `FocusQuizRunner.tsx` | Reading docs (10 pages) -> Video lecture -> Verification checklist with mandatory gates -> Single-item focus quiz. |
| **Telemetry & Anti-Cheat** | `FocusQuizRunner.tsx` | Click telemetry recorded throughout reading/checklist. Anti-cheat hides correct answers on failure, prompting candidate retry. |
| **Diverse Question Types** | `FocusQuizRunner.tsx` | MCQ, Multi-select checkbox, Free text/paragraph, File upload (PDF/Doc), and Mindmap/Workflowy/XMind/Figma URLs with live regex check. |
| **Question Reporting & Bug Triage** | `FocusQuizRunner.tsx`, `AnalyticsDashboard.tsx` | Candidate report modal (`feedback`, `bug`, `typo`, `dispute`) dispatches to `/wp-exam/v1/reports`; instructor triage card with filter chips and resolve actions. |
| **Analytics & Public Sharing** | `AnalyticsDashboard.tsx` | KPI cards, question-level breakdown, High Failure Alert badges (>40%), public sharing toggle, candidate difficulty preview. |
| **Multi-Theme Engine** | `src/themes/theme-definitions.ts` | `letterly`, `bright-gold` (Rise Up Asia amber/black), `dark`, `white`, and dynamic JSON theme injector. |
| **AI Instruction Studio** | `AIInstructionStudio.tsx` | Prompt contracts for doc-to-curriculum and screenshot-to-quiz, plus real-time JSON schema validator. |
| **Email Gateway & Backups** | `EmailSettings.tsx`, `BackupManager.tsx` | SMTP config, recipient chains, dispatch cadence (`per_section`, `end_of_day`, `end_of_week`), rotating zip backups. |
| **Grounded Specifications** | `02-spec/21-app/05-hierarchical-learning-and-exam-system/` | Verbatim text and 5 channel specs registered in `02-spec/21-app/01-index.md`. |
